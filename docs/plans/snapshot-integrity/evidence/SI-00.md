The delivery package includes the exact five baseline archives, normalized
validation results, local control-test log, source-tree identity and a patch
against the recorded bootstrap source. From its candidate directory:

```sh
python -m unittest discover -s scripts/si00 -p 'test_*.py' -v
python scripts/si00/evidence.py /path/to/baseline-directory \
  --checkout 5d18caf81a2bb00a39f0584c894e9b31fbdd60e6 \
  --profile windows-x86_64 \
  --inventory docs/plans/snapshot-integrity/bootstrap/baseline-tests.json
```

Offline validation does not use --verify-binaries because the old archives do
not include executable bytes. The proposed workflow uses that option on the
actual runner. Full C11 provenance/approval gates surround the arithmetic helper;
a JSON APPROVED string is not authentication of a reviewer.
